# Sistema de gerenciamento de brinquedos

O sistema permite executar as quatro operações do CRUD:

1- Create: cadastro de brinquedos
2- Read: listagem de brinquedos
3- Update: edição de brinquedos
4- Delete: remoção de brinquedos

## Instruções para a execução

1- Faça o download do sistema e o insira dentro da pasta 'htdocs'

2- execute o Apache e o MySQL através do XAMPP

3- execute o banco de dados do sitema através do phpMyAdmin

4- Acesse o sistema através do navegador utilizando 'localhost'

5- Utilize as funções desejadas do sitema de gerenciamento
